# Synthetic Datasets — 20 Dashboard Challenges

One synthetic dataset per assignment challenge (plus a second sheet for
Challenge 13). All files are **fictional** — generated by a seeded script, no
real personal data, safe to share in a classroom.

## How to get them

- **Browse / download:** open [`datasets/index.html`](index.html) for the
  themed catalog, or grab the CSVs directly from this folder on GitHub
  (click a file → **Download raw file**).
- **Clone the repo:** `git clone https://github.com/ecologictribe/grill-me-dashboards.git`
  — datasets land in `datasets/`.
- **Power BI:** *Get Data → Text/CSV* and point at the file. **HTML path:**
  fetch/inline the CSV however your stack prefers.

## Cross-references (where each dataset fits)

- **File number = challenge case number:** `challenge-05-*.csv` belongs to
  case **C5** in [challenges.txt](../challenges/challenges.txt) (Part B) and to
  card **#5** on the [assignment page](../assignments/index.html#challenges).
- **Case → failure mode:** challenges.txt Part A maps every case to the
  foundational failure mode it teaches (tutorial Parts 1–4).
- **Method to solve it:** the [Challenge-Grill Method](../tutorials/grill-method.html)
  turns a dataset's trap into spec decisions; source prompt:
  [system_prompt_grill_me.md](../prompts/system_prompt_grill_me.md).
- **Series theory:** [tutorials/index.html](../tutorials/index.html) — each
  part page links its own cases + datasets ("Put It Into Practice" box).
- **Verification:** [grader/grader.v2.js](../grader/grader.v2.js) checks HTML
  dashboards against the gates; self-evaluation steps live in the
  [assignment](../assignments/index.html#self-eval).

## Regenerating (trainers only)

```bash
node scripts/generate-datasets.js
```

Seeded PRNG (`20261029`) → the script always produces byte-identical files.
Never edit the CSVs by hand; change the script instead.

**Last updated: 2026-10-29T19:00:00+05:30.** The generator also writes
[`meta.json`](meta.json) — the per-dataset manifest (case, title, rows,
bytes, last_updated). Bump `BUILD_STAMP` in the script whenever datasets
change; the catalog page shows the same date per card.

## Rules of use

1. **You may not fabricate your own rows** for a declared challenge — the
   dataset is part of the spec conversation ("where did this data come from?").
2. **You may not edit the CSV** except through a documented, reversible
   transformation shown in your report (that transformation is decision D-something).
3. Bring dataset questions to the grill — "my chart looks wrong" is usually
   "my data has a trap", and identifying the trap *is* part of the marks.
