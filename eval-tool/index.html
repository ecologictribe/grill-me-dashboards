🛡️ What's Happening — and What's Safe

            
    
                
  • Your file stays yours. It is read into this page and executed inside a sandboxed browser frame — it is never uploaded anywhere. No server sees your dashboard.
    • 
                
  • The sandbox is one-way glass. Your page's scripts run (so the gates measure the real rendered dashboard — live DOM, canvas and all), but they cannot touch this tool, its buttons, or your other browser tabs.
    • 
                
  • Same gates as the offline kit. Baseline · CVD palette · DOM budget · F-pattern grid — identical checks to self-grade.bat and grader.v2.js, so a 4/4 here means a 4/4 there. No internet after this page loads.
    • 
                
  • Honesty model unchanged. The verdict describes the file you loaded. It's self-reported evidence — you defend it live, and the trainer can re-run any file. Fooling the gate ≠ passing the viva.
    • 
            

        


        
        

            
🔍 The 4 Gates in Plain English

            

                

                    
📏 Gate 1 — Baseline

                    
Does every chart start its measuring axis at zero? Truncated axes exaggerate differences — the classic way charts lie. Fix: set your y-axis minimum to 0 (or state why not).

                

                

                    
🎨 Gate 2 — Colour & Shapes

                    
Can a colourblind colleague still read your series? Your source must carry all 3 colourblind-safe palette tokens and at least 2 distinct shape markers (● ▲ 🛑) so colour isn't the only signal.

                

                

                    
⚡ Gate 3 — Speed

                    
How heavy is the live page after your scripts run? Under 1,500 nodes keeps it snappy on a lab PC or phone — plus at least one canvas/SVG layer doing the real drawing.

                

                

                    
📐 Gate 4 — Layout

                    
Is there a real grid or flex layout, 2+ semantic headings (so it reads top-left → down, like people scan), and a mobile breakpoint below 768px?

                

            

            
Each ✗ maps to a spec decision that drifted — not to you being "bad at this". Fix the decision, drop the file again. Gate theory lives in the Challenge-Grill Method; why these exact gates exist: Part 8 — Validation · VALIDATION.md.
