🎯 How This Series Works

  • 1 · Learn the method first: the Challenge-Grill Method teaches you to repoint Matt Pocock's Grill Me prompt at a challenge — the AI interrogates the failure mode and the answers write your Spec Doc.
  • 2 · Read short: each part decodes its challenges with a real case study and a plain-English "what's actually going on".
  • 3 · Grill your challenge: each part ships a scoped grill prompt — run it, capture your numbered decisions before writing any code.
  • 4 · Build small: prototype the fix your Spec Doc describes, in a single HTML file.
  • 5 · Grade yourself: every part ends with a rubric whose Gate 0 checks the process (did you grill?) and Gates 1–4 check the artifact — the validated Anti-Drift Gates, run by you.
  • 6 · Certify: pass every gate to mark the part complete. Progress is saved in this browser.

📋 Before You Begin

  • Basic HTML/CSS and any chart library (or plain canvas). No prior dashboard experience required.
  • Optional but recommended: read Part 7 (Grill Me Method) and its validation Part 8 — your self-grading rubric comes from there.
  • Self-grading kit: node + npm install jsdom in the ecologictribe/grill-me-dashboards repo gives you the hardened grader.v2.js.

🔑 Why Self-Grading?

  • Reading a case study is passive. Building a fix and passing your own boolean gates is how the lesson sticks.
  • Your rubric is the validated one: baseline integrity, CVD palette + shape redundancy, DOM budget, and metric/structure checks — the gates that survived adversarial testing in Part 8.
  • A part is only "Certified" when you checked every gate against your own artifact. No gate, no glory.
