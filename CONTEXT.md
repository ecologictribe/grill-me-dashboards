# CONTEXT.md — Project Memory (grill_me_dashboard)

Living project memory. Update this file whenever structure, dates, or
conventions change. All artifacts live INSIDE this repo (global rule); files
are never deleted — retired uncommitted artifacts go to `.quarantine/`.

## What this project is

1. **Tutorial validation** — a complete working implementation of the Aplly.xyz
   tutorial "Matt Pocock's Grill Me Method & Drift-Proof Evaluation Frameworks"
   (Grill prompt → Spec Doc → gated build → automated grader), with findings
   F1–F7 recorded in `VALIDATION.md`. The tutorial's grader was kept verbatim
   (`grader/grader.js`); a hardened `grader/grader.v2.js` fixes F2 (OR-logic
   palette check), F3 (static DOM), F4 (whitespace-fragile CSS matching).
2. **Teaching series** — "Data Visualization Challenges, Decoded" in
   `tutorials/` (aplly.xyz visual theme): `grill-method.html` (the
   Challenge-Grill Method lesson), `part-1..4.html` covering all 22 failure
   modes, each with a 🤺 Grill step + GATE 0 (spec-first) + 5-gate self-rubric.
3. **Class assignment** — `assignments/index.html`: issued **29 Oct 2026**,
   due **5 Nov 2026** via **eflow portal**, one PDF
   (`RollNo_Name_DatavizAssignment.pdf`); 3 of 20 challenges → 3 separate
   reports; HTML default (auto-graded by the self-grading kit), Power BI
   optional (**+2/report Power BI bonus, capped +5**);
   graded 5–7 min presentation on 5 Nov; scorecard A(30)+B(30)+C honesty
   (15)+D delivery (25)+E bonus; pass 60; Seal of Honour ≥85 & |self−trainer|≤3.
   Class of ~50; recommendation: 1 easy + 1 medium + 1 hard.
4. **Synthetic datasets** — `datasets/`: 21 seeded CSVs (one per case
   challenge; C13 has two sheets), each CONTAINING the challenge's trap
   (outage-as-zero rows, 1,200-row cap crossing, mixed cadence, missing
   units, PII, hardcoded year, sarcasm scored positive...). Generated by
   `scripts/generate-datasets.js` (seed 20261029, byte-reproducible — never
   hand-edit CSVs). Catalog: `datasets/index.html`; docs/rules: `datasets/README.md`.

## Challenge dataset (canonical source: `challenges/challenges.txt`)

- **Part A** — the 22 failure-mode challenges (originals verbatim), each with a
  COVERAGE line (series part / case / dataset). Taught in `tutorials/part-1..4.html`.
- **Part B** — 20 case challenges **C1–C20** (the assignment's challenges; same
  numbering on the assignment page and dataset files `challenge-NN-*.csv`).
- **Part C** — **C21–C27**: proposals for the 7 uncovered failure modes
  (#1 uncertainty, #3 networks, #4 geospatial, #14 ML explainability,
  #16 interactivity overhead, #18 auto-insight context stripping, #19 AR/VR).
  Not in the current assignment until the trainer adopts them + a dataset is built.
- **Part D** — template for adding challenges (generator → catalog → assignment →
  part page → COVERAGE line).

## Conventions

- **Last-updated stamps:** every HTML page carries
  `<meta name="last-updated" content="…">` + a visible "⏱ Last updated" in
  the footer; the generator's `BUILD_STAMP` constant (in
  `scripts/generate-datasets.js`) drives `datasets/meta.json` — the
  per-dataset manifest (case, title, rows, bytes, last_updated). Bump the
  stamp when content changes; the probe enforces all of it.

  headers, Sora/DM Sans/Fira Code, Tailwind CDN + custom CSS, card layout,
  badges, progress bar, "From the Desk of Puneet Arora" attribution.

  `apllyAssignment`.

  Power BI / presentation), datasets (21 CSVs, catalog links resolve, key traps

## Cross-link map (student navigation)

Every page links sideways, so students can cross-reference from any starting
point. The web (all links relative):

- **tutorials/index.html** — hub: parts, method, assignment, datasets chip,
  "🗂 Working Files" (prompts, spec, dashboard, grader, challenges.txt).
- **tutorials/grill-method.html** — "🗂 The Full Toolkit" table: prompts
  (.md), spec, dashboard, graders, challenges.txt, datasets, assignment.
- **tutorials/part-N.html** — grill step links method + source prompt; each
  part has a "🎯 Put It Into Practice" box: its failure modes → assignment
  cases C# → dataset CSVs (+ open-proposal pointers to challenges.txt Part C).
- **datasets/index.html** — intro: card number = assignment card number,
  method + challenge-bank links; every card has a 🤺 method chip.
- **assignments/index.html** — workflow "toolkit" table (method, prompts,
  spec, dashboard, grader, challenges.txt, tutorials); every challenge card
  has 🤺 (method) + 📦 (dataset CSV) chips; declaration links the source
  prompt; self-eval links grader.v2.
- **datasets/README.md** — cross-reference section (file ↔ case ↔ failure
  mode ↔ method ↔ series ↔ grader).

Probe enforces the key edges (parts → prompts/datasets/assignment; method →
toolkit; assignments → prompts/grader/spec/dashboard; catalog → method).
