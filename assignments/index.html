Why HTML Is the Default — and What Power BI Students Do Instead

The automated grader.v2 reads HTML files only — a .pbix is a binary project with no web page inside, so no script can check its gates. That's why HTML is the default path, and there are two easy ways to run the checks: drop your file on the browser Eval Tool (nothing to install, works on phones), or use the offline Self-Grading Kit (one double-click, self-grade.bat). Both check the same 4 gates. If you choose the optional Power BI path, your evidence = exported page images checked by eye against the same four gates (screenshot each gate's check in your PDF). Doing the exercise by hand twice teaches you more than the script ever could — that's exactly why the Power BI path earns bonus marks.

📸 How to Self-Evaluate — and Share Your Score Screenshot

Your self-score is part of the submission, not a private rehearsal. You grade your own three reports with the scorecard above, capture it, and put the screenshot into your PDF. Here is exactly how:

  1. Open this page in the browser you will screenshot from (assignments/index.html on GitHub or your cloned repo). The scorecard saves as you type — but scores live in that browser's storage, so don't fill it on one machine and capture on another.
  2. Evaluate report by report, evidence first. For each row: run the check on your actual artifact before entering a number. A1–A4 (spec discipline ×3), B1–B3 (the 4 gates per report), D1–D4 (delivery). Tick the Power BI boxes (E) where they apply. Enter only in the Self column.
  3. Read the verdict banner under the table — it shows your Self total and claim status. If your claim lands ≥ 85, you are claiming the Seal of Honour: every point must survive the trainer's question "show me the evidence".
  4. Capture the screenshot: press Win + Shift + S (Snipping Tool) and select the entire scorecard — the header row (Component / Max / Self / Trainer), every scored row, the TOTAL row, and the verdict banner. Fill the Student name + date fields first; leave the Trainer column blank — that column belongs to Puneet Arora. (Ctrl+P → Save as PDF of just this page works too.)
  5. Paste it into your PDF as the last page, labelled "Self-Evaluation Scorecard". Name, roll number, and your Self total must be readable. Take the screenshot before you clear browser data or switch machines.
What "self-evaluation" must cover — per report
  • The 4 artifact gates, run on the real artifact: HTML reports — attach the Self-Grading Kit output showing the gates passing (screenshot the self-grade.bat window); Power BI reports — hand-check each gate on the exported page images and paste the checked image.
  • Gate 0 / spec discipline: your grill transcript and decisions dated before the artifact — timestamps are the evidence.
  • The honesty component (C1): your screenshot is your claim. |Self − Trainer| ≤ 3 → full 15 marks; ≤ 7 → half; > 7 → zero. Inflating the self-score never lowers the trainer's number — it only forfeits C1.
Submission Checklist — Self-Evaluation
  • ☐ Scorecard screenshot on the PDF's last page (TOTAL row + verdict visible)
  • ☐ Grader output screenshot per HTML report · gate hand-check per Power BI report
  • ☐ Trainer column left blank · Student name + date filled
  • 📱 On a phone: long-press a card's Dataset chip → "Download link" to save the CSV (raw files open in a new tab by design).
